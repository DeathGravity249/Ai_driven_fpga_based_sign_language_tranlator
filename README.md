# AI-Driven FPGA-Based Sign Language Translator

An AI-powered Sign Language Translator that recognizes Indian Sign Language (ISL) hand gestures using Computer Vision and Deep Learning. The project is designed with a future FPGA implementation in mind, where the trained model can be deployed on FPGA hardware for real-time inference.

## 📌 Project Overview

The system captures hand gestures through a webcam, processes them using computer vision techniques, and classifies the gesture using a Convolutional Neural Network (CNN). The recognized gesture is then displayed as readable text.

This project demonstrates the integration of Artificial Intelligence, Computer Vision, and FPGA-based hardware acceleration.

## 🏗 Project Workflow

1. Capture hand gesture using webcam.
2. Detect hand landmarks with MediaPipe.
3. Preprocess the captured image.
4. Classify the gesture using a trained CNN model.
5. Display the corresponding text output.
6. Prepare the design for future FPGA implementation.
