A real-time sign language translation system that converts Indian Sign Language gestures into text and speech using AI and computer vision, with FPGA acceleration for optimal performance.

## 🚀 Features

- **Real-time Gesture Recognition**: Live camera processing for instant sign language translation
- **AI-Powered Translation**: Deep learning models trained on Indian Sign Language datasets
- **Web Interface**: User-friendly Flask-based web application
- **FPGA Acceleration**: Hardware-optimized processing for low-latency performance
- **Multi-Modal Output**: Text and speech output for translated signs
- **Upload Support**: Process pre-recorded videos and images

## 🛠️ Technology Stack

### Backend
- **Python 3.8+** - Core programming language
- **Flask** - Web framework
- **TensorFlow/Keras** - Deep learning model training and inference
- **OpenCV** - Computer vision and image processing

### AI/ML

- **Transfer Learning** - Model optimization
- **Data Augmentation** - Training data enhancement
